## Features

- Full-screen, window or region capture with a built-in annotation editor: arrows, boxes, text, highlighter and **blur for sensitive data**
- GIFs and short recordings with **no watermark and no time limits**
- System audio + microphone, native-quality encoding (FFmpeg bundled)
- Everything runs and stays on your PC — no accounts, no uploads

## Download (Windows 10/11)

### ➡️ [**Download CapturaPro (installer .exe)**](https://github.com/Octonove/capturapro/releases/latest/download/CapturaPro-Setup.exe)

Direct download, no sign-up. If Windows shows *"Windows protected your PC"* (normal for new unsigned apps): click **More info → Run anyway**. Installs without administrator rights.
